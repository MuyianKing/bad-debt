# 布局与交互

> 本文件覆盖首页抽屉、哪吒头图、沉浸式顶栏、负层光斑与分类拖拽。色彩与组件基线见 `20-ui-basics.md`。

## 首页侧滑抽屉

- 首页左上角为**侧滑抽屉**（index.vue 的 `.drawer` + `.drawer-mask` + `.page-main`，菜单项与图标定义在 `drawerMenus`；新增一级页面入口时同步加进去）。**抽屉是自绘跟手面板，不要再改回 wd-popup**：要求"抽屉滑出宽度 = 首页右移宽度、且都按手指位移实时变化"，wd-popup 的挂载与 enter 过渡有数百毫秒延迟、无法跟手。统一由一个 `drawerProgress`（0~1）驱动三样东西——抽屉 `translate3d(-W×(1-p))`、首页 `translate3d(W×p)`、遮罩 `opacity: p`（W 取 `min(250px, 78vw)`，与 `.drawer` 的宽度一致，改宽度要同步 `DRAWER_MAX_W`）；拖动中三者的 `transition` 必须是 `none`，松手后才交给 280ms 过渡吸附（过半展开）。手势在整个首页与抽屉上生效（根节点 touch 事件冒泡），按水平/垂直位移比判方向，避免抢页面滚动；悬浮加号不受位移影响（fixed），按同一进度淡出。
- 抽屉底部的自动记账状态是**全量权限聚合**：无障碍未开显示「自动记账未开启」；无障碍已开但悬浮窗 / MIUI「后台弹出界面」/ App 通知权限 / 电池优化 / 通知使用权 / 无障碍自恢复任一未开，显示「自动记账异常」并列出缺项；全部就绪才显示「自动记账运行中」。不要退回成只看无障碍一个开关；后台保活、从多任务隐藏是用户可自选的开关，不参与判定。权限状态在 `load()` 与展开抽屉时刷新，设置页授权后返回即可看到变化。

## 首页头图角色

- **首页头图右侧的角色**：当前是哪吒，三张透明 WebP 在 `static/nezha/`，由 `common/mascots.js` 的 `MASCOTS` 统一配置（表情、显示宽度 `widthRpx`、上提量 `bottomRpx`、头像 `headSrc`），页面里**右侧固定留 20rpx 间距，不要贴边裁切**。**角色与主题解耦**：`THEME_MASCOT` 决定每套主题用哪个角色；当前哪吒已启用，悟空已预置但 `ready: false`（素材到位前回退到哪吒），沙僧仍映射到哪吒。新增/启用角色只改 `MASCOTS` 和 `THEME_MASCOT`，页面不要按 `theme.id` 写 if/else，也不要写死角色名或图片路径。设置页「外观 → {角色}表情」切换基础表情；`autoMood` 开启时，空态/成功态自动换 `mood` 对应的表情，关闭后固定用基础表情。通用组件 `components/mascot-face/mascot-face.vue`（`mood` / `size` / `head` / `mode`），**主角色一屏最多一处**（记一笔输入行 ≤72rpx 的表情指示不算），分类图标、图表、金额与账单行等数据区不放。**头图原有的两个装饰圆环（右上大弧线 + 人物后面的小圆）已按要求删除，不要再加回去**；角色只在默认渐变头图显示，自定义 `heroImg` 时随 `.hero-deco` 一起隐藏。**月收入 / 本月结余两列直接排在「本月支出」金额下方（`.hero-stats`），不要再做成压在头图底边的悬浮卡**，人物整张脸（含下巴）都要露在外面；上提量仍由各表情的 `bottomRpx` 控制，换图后浅色主题与沙僧黑各看一遍。素材是网络免抠图（花瓣），仅本地自用，上架前确认授权。
- **角色在各页的落点**：首页头图 + 抽屉 92rpx 头像；首页空态用 `head` 模式（152rpx）；**日历选中日摘要与账单列表合并为同一张玻璃卡**（不再拆成摘要卡 + 列表卡）：摘要区有账单时右侧固定 158rpx 整身角色（当前筛选结果里有进账且未倒挂用「大笑」`success`，其余用基础表情），左侧保留日期、笔数、收支合计与「角色名：台词」；摘要与列表之间用 1rpx `--c-line` 的 `.day-divider` 分隔，列表行之间继续沿用 `bill-list` 自带的 `border-top`，列表用 `:flush="true"` 去掉内层 `.bl-group` 的卡片底、圆角、阴影，由外层卡统一承载；空日摘要只留日期和台词，卡片下半部分由 128rpx `head` 空态接手——两种角色不同时出现，保证一屏一只；**记一笔页分类区右下角固定 145rpx 整身角色 + 台词**（绝对定位在 `.cat-area` 内，不随分类列表滚动、不占键盘高度；分类滚动内容底部留 190rpx，保证滚到底时最后一行不被角色压住），输入行常驻 72rpx 头像做收支表情指示（填收入金额时切 `success`），保存成功或金额不合法时弹 112rpx 表情反馈（瞬时，不按「一屏一只」算）；台词按收入/支出分写：空态「进账多少？」/「这笔花在哪？」，输入后「进账啦」/「花哪儿了？」，非法金额提示需大于 0；统计不在空态放角色，改为总览卡常驻 190rpx 整身角色（和首页同一套整图展示）——结余为负用「不服」（`warn` 别名），结余为正用「大笑」（`success`），持平 / 无账单用基础表情；总览只保留收入 / 结余两项，不再显示日均支出，排版与首页 `.hero-stats` 一致（标签在上、金额在下、细分割线、左对齐，不均分整行）。首页空态、日历空态与抽屉头像外面套圆形 `--c-primary-weak` 底 + `--c-primary-tint` 细边；抽屉、记一笔输入行表情指示和保存反馈分别属于独立浮层、小尺寸状态指示与瞬时反馈，不计入「一屏一只」。

## 首页顶部导航吸顶

- **首页顶部导航（菜单 / 月份切换 / 日历 / 统计）是吸顶栏**：`.hero-nav` 用 `position: sticky; top: 0` 贴在 `.page-main` 顶部，负 `margin-bottom` 让头图铺到页面最上方，头图里用 `.hero-nav-space` 留出导航行高。`onPageScroll` 超过 8px 后加 `.hero-nav-solid`（`--glass-nav-bg` + blur），图标从白色换成 `theme.ink`、月份文字换 `--c-text`，APP 端状态栏同步换深色（深色主题保持浅色图标，见 `applyStatusBarStyle`）。不要让导航跟着头图滚走，也不要把它塞回头图内部。

## 内页沉浸式顶栏

- **内页顶部沉浸式**：`wd-navbar` 不是天然沉浸的——默认白底会把状态栏和标题糊成一条白带。做法见 calendar.vue：顶栏底色走 `custom-style`（静止态 `background-color: transparent`，让页面底色/光斑直通状态栏；`onPageScroll` 超过 8px 后换成 `--glass-nav-bg` + blur 转毛玻璃，避免列表从标题下穿过，同时 `:bordered="navSolid"` 只在滚动态留分割线）。**踩过的坑**：页面 `<style>` 在 H5 按 `data-v-*` 作用域编译，而 `custom-class` 落在组件内层元素上（不带页面 data-v），页面里写 `.cal-navbar{...}` 匹配不到；组件外层底色只能用 `custom-style`，或把类写进 App.vue 全局样式（`.glass-nav` 即此机制）。**通用规则**：页面 scoped 样式要改 wd-* 组件内部节点（如 `wd-cell__left/__right`）必须用 `:deep()` 穿透，普通后代选择器会静默不生效。状态栏要真沉浸还需 manifest `app-plus.statusbar` 用**正确键名 `immersed`**（不是 `immersive`），并把 `pages.json` 的 `navigationBarBackgroundColor` 设为页面底色（沉浸失效时状态栏至少与页面同色）。

## 日历页

- **日历页不提供记账入口**：记账入口只保留首页的 `app-fab`。日历页不放底部加号、摘要卡「记一笔」按钮，空态也不可点击记账；页面只做查看、编辑与删除，保存/删除返回后由 `onShow` 重载当月账单。不要再用「当前选中日期打开记一笔」的 `goAdd` 路径把入口加回来。

## 负层光斑

- **负层光斑的前提**：光斑写 `.bg-blobs { z-index: -1 }` 时，页面根节点 `.page` 必须同时 `position: relative; z-index: 0` 建立层叠上下文，否则光斑会被页面底色整块盖掉（H5 必现；日历页的光斑因此需要按此修）。注意新代码仍禁止新增光斑/光效（见 `20-ui-basics.md`），此条只约束存量页面。

## 分类排序

- 分类管理的排序交互是**长按拖拽**（categories.vue 的 startDrag/onDragMove/onDragEnd，矩形命中 + 松手落位 + 立即持久化），不要改回点菜单移一步的旧交互；子类面板渲染在父类行的紧下方（cat-block 内）。
- **拖动必须有实时让位动画**：被拖的父类**整块**（行 + 展开的子类面板）跟手平移，其余块按当前目标槽位整块上/下让位（`transform` + 200ms 过渡）；子类按宫格的**横纵坐标**命中，受影响的格子平移到前/后一个格位（可跨行对角移动），末尾「添加子类」不是排序目标。松手先把被拖条目吸附到目标槽位（200ms），动画结束再改数组并 `persist()`，不要松手瞬间硬跳；`to === from` 时滑回原位。父类命中用 `.cat-block` 矩形（含面板），让位距离取被拖块高度，这样不同高度的块也能严丝合缝。
- **拖拽期间必须锁住页面滚动**：App 端页面 `<script setup>` 跑在逻辑层（`app-service.js`），**那里没有 `document`**，在页面脚本里挂 `document.addEventListener('touchmove', ...)` 是死代码（H5 同层可用，但统一走同一份实现）。锁滚动写在 categories.vue 的 `<script module="scrollGuard" lang="renderjs">` 里：页面渲染时挂**捕获阶段 + 非 passive** 的 `touchmove` 守卫，监听视图层派发的 `longpress` DOM 事件（与 `@longpress` 是同一个事件，350ms/10px）判定拖拽开始，拖拽中 `preventDefault`，`touchend/touchcancel` 复位，`touchstart` 兜底自愈。不要把这段逻辑挪回 `<script setup>`。

## 记一笔子类展开

- 记一笔页选中带子类的父类时，子类面板插在**父类所在行的紧下方**（`.cat-grid` 用 5 列 grid，面板 `grid-column: 1 / -1`，`subRowEndIndex` 决定插在第几个父类之后），不要放回宫格末尾或改成弹层；面板顶部的小箭头由 `subCaretLeft` 计算，对准父类列中心。**子类只列真实子类，不要再加「全部」选项**：未选子类时按父类名记账。
