# 布局与交互

> 本文件覆盖首页抽屉、角色头图、吸顶导航、分类拖拽与子类展开。色彩与组件基线见 `20-ui-basics.md`。

## 首页侧滑抽屉

- 首页左上角为**侧滑抽屉**（`HomeScreen` 的 `drawerProgress` + `Drawer` 面板）。抽屉宽度 `min(250.dp, 屏宽 × 0.78)`，首页内容与抽屉用 `graphicsLayer { translationX = drawerWidthPx * progress }` 同步平移，遮罩 `alpha = progress`。
- 手势用 `pointerInput` + `awaitEachGesture` 在整个首页上生效：按下后按水平/垂直位移比判方向，避免抢列表滚动；拖动中实时更新 `drawerProgress`，松手后按是否过半用 280ms `tween` 吸附到 0 或 1。不要改回只在菜单按钮上触发的单向动画。
- 返回键在抽屉打开时先关抽屉（`BackHandler(enabled = drawerProgress > 0.01f)`）；首页按返回键才 `moveTaskToBack(true)`。
- 悬浮加号 `AppFab` 固定底部、不随抽屉位移，按同一进度淡出（`alpha = 1 - drawerProgress`）。

## 首页不做权限判断

- 首页与抽屉只展示账单数据与导航入口，不查询无障碍、悬浮窗、通知、电池优化等任何权限状态，也不显示权限提示条或「自动记账运行中/异常」聚合状态。权限检测、授权入口与自恢复统一放在设置页（`AppState.onResume()` 自增 `resumeToken`，页面用 `LaunchedEffect(app.resumeToken)` 重载）。首页不再重复判断。

## 首页头图角色

- 首页头图右侧的角色由 `MascotFace(app, mood, size, head)` 渲染，素材在 `app/src/main/assets/mascots/`，由 `data/Mascots.kt` 统一配置（表情、整身/头像资源、默认表情）。页面里**右侧固定留出间距，不要贴边裁切**。
- **角色与主题解耦**：`THEME_MASCOT` 决定每套主题用哪个角色；悟空已预置但 `ready = false`，素材到位前回退到哪吒。新增/启用角色只改 `Mascots.kt`，页面不要按 `themeId` 写 if/else，也不要写死角色名或图片路径。
- 设置页「外观 → {角色}表情」切换基础表情；`autoMood` 开启时，空态/成功态自动换 `mood` 对应的表情，关闭后固定用基础表情。
- **主角色一屏最多一处**（记一笔输入行 ≤72 的表情指示不算），分类图标、图表、金额与账单行等数据区不放。角色只在默认渐变头图显示，自定义 `heroImg` 时随装饰一起隐藏。
- **月收入 / 本月结余两列直接排在「本月支出」金额下方**，不要再做成压在头图底边的悬浮卡；人物整张脸（含下巴）都要露在外面，角色贴紧头图底边。

## 角色在各页的落点

- 首页头图 + 抽屉头像；首页空态用 `head` 模式（152）；**日历选中日摘要与账单列表合并为同一张玻璃卡**：摘要区右侧固定整身角色（当前筛选结果里有进账且未倒挂用 `success`，其余用基础表情），左侧保留日期、笔数、收支合计与「角色名：台词」；摘要与列表之间用 1 分隔线，列表用 `flush = true` 去掉内层卡片底，由外层卡统一承载；空日摘要只留日期和台词，卡片下半部分由 128 `head` 空态接手——两种角色不同时出现。
- **记一笔页分类区右下角固定整身角色 + 台词**（绝对定位在分类区，角色底边贴紧键盘上沿，不随分类列表滚动、不占键盘高度；分类滚动内容底部留出足够空间，保证最后一行不被角色压住）；输入行常驻小头像做收支表情指示，保存成功或金额不合法时弹表情反馈（瞬时，不按「一屏一只」算）。
- 台词按收入/支出分写：空态「进账多少？」/「这笔花在哪？」，输入后「进账啦」/「花哪儿了？」，非法金额提示需大于 0。
- 统计不在空态放角色，改为总览卡常驻整身角色；结余为负用 `warn`（映射到「不服」），结余为正用 `success`（大笑），持平/无账单用基础表情。
- **分类管理页只在顶部提示条常驻头像 + 台词**（常态报操作；拖拽时切「不服」、松手/保存后短暂切「大笑」，属于瞬时反馈），不进入分类行、分类图标与拖拽块。

## 首页顶部导航吸顶

- 首页顶部导航（菜单 / 月份切换 / 日历 / 统计）是**吸顶栏**：`HomeScreen` 的导航 `Box` 始终固定在 `LazyColumn` 上方，列表滚动后按 `navSolid`（`firstVisibleItemIndex > 0` 或 `firstVisibleItemScrollOffset > 8`）把背景切成半透明玻璃底，图标从白色换成 `palette.text`。
- 首页 `navSolid` 同时写入 `app.homeNavSolid`，`MainActivity` 据此切换状态栏图标深浅；抽屉打开时强制 `homeNavSolid = false`（保持白色图标）。不要让导航跟着头图滚走。

## 内页沉浸式顶栏

- 内页统一用 `TopBar(title, onBack, solid = ...)`：未滚动时背景透明，让页面底色直通状态栏；滚动超过阈值后 `solid = true` 切半透明底，避免列表从标题下穿过。
- 顶栏外层用 `statusBarsPadding()`；不要写死状态栏高度，也不要让顶栏和状态栏之间出现白带。
- 页面背景与顶栏之间不要加额外的实心色块；沉浸效果由 `MainActivity` 的 edge-to-edge + 透明系统栏保证。

## 日历页

- **日历页不提供记账入口**：记账入口只保留首页的 `AppFab`。日历页不放底部加号、摘要卡「记一笔」按钮，空态也不可点击记账；页面只做查看、编辑与删除，保存/删除返回后由 `resumeToken` 重载当月账单。不要再用「当前选中日期打开记一笔」的路径把入口加回来。

## 负层光斑

- 原生版不使用负层光斑/光晕。不要在页面里用 `Canvas`、`Brush.radialGradient` 或半透明圆形伪造氛围光；层次只靠 `glass` / `solidCard` 的描边与阴影。

## 分类排序

- 分类管理的排序交互是**长按拖拽**（`CategoriesScreen` 的 `detectDragGesturesAfterLongPress`，矩形命中 + 松手落位 + 立即持久化），不要改回点菜单移一步的旧交互；子类面板渲染在父类行的紧下方。
- **拖动必须有实时让位动画**：被拖的父类整块（行 + 展开的子类面板）跟手平移，其余块按当前目标槽位整块上/下让位；子类按宫格的横纵坐标命中，受影响的格子平移到前/后一个格位（可跨行对角移动），末尾「添加子类」不是排序目标。
- 松手先把被拖条目吸附到目标槽位，动画结束再改数组并 `saveCategories()`，不要松手瞬间硬跳；`to == from` 时滑回原位。父类命中用整块矩形（含面板），让位距离取被拖块高度。
- 拖拽期间锁住列表滚动（拖拽手势消费事件），不要额外挂全局触摸守卫。

## 记一笔子类展开

- 记一笔页选中带子类的父类时，子类面板插在**父类所在行的紧下方**（5 列宫格，`subRowEndIndex` 决定插在第几个父类之后），不要放回宫格末尾或改成弹层。
- **子类只列真实子类，不要再加「全部」选项**：未选子类时按父类名记账。
