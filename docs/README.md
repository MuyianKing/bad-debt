## 维护约定

- 一个主题一篇文档；新增约束先判断是否跨模块，通用底线写回 `AGENTS.md`，其余写进对应文档并更新本索引。
- 文档用确定事实描述（文件路径、类/函数名、SharedPreferences key、表字段、页面枚举），不要写「相关代码」这类模糊指代。
- 代码里的约定发生变化（键名、函数名、存储 key、表结构、页面枚举）必须同步改对应文档，否则视为改动未完成。
- 文档之间不要复制整段内容；需要时用相对链接引用，避免两处口径漂移。
